mbrock/filnix

Every C pointer checked. A whole Linux system in Nix. A compiler whose checks are proved in Rocq.

Filnix builds Nixpkgs packages, and a complete NixOS userland, with Fil-C, Filip Pizlo's memory-safe C and C++: an out-of-bounds access or a use after free stops the program instead of corrupting its memory. Beside the distribution it builds nanofil, a C compiler in Prolog that makes each of Fil-C's checks a term in its IR, with a Rocq proof that a validated program never makes an unchecked access.

  • Compile C in the browser
