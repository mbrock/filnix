This site renders the repository's Nix, Prolog and Rocq source from their syntax trees rather than as plain text. Nix bindings appear as tables, Prolog clauses as terms, Rocq inductive types as tables and Rocq relations as inference rules. Each name links to the place it is defined.

  • Nix Nix files, including the NixOS and finix modules, the port definitions in ports.nix and an index of the module options.
  • PrologThe modules of nanofil, with each predicate's documentation and examples you can run.
  • RocqThe files of the formal campaign: the model of nanofil's IR, the soundness proof and the program proofs.
  • Concepts terms that the Prolog, the Rocq and the documents share. Each is explained once and linked from all three.
  • Playgroundnanofil running on SWI-Prolog in WebAssembly. It compiles C you type and shows the syntax tree, IR and assembly.
  • dterm workbenchThe same terms drawn side by side under different settings, used to tune how these pages are drawn.

dterm explains how the drawing works.
